# Blockchain-Enabled Halal Certification System

This repository contains a prototype halal certification system built using **Hyperledger Fabric**.  
The system demonstrates how blockchain can be used to support halal certification workflows with traceability, access control, and auditability.

## Repository Structure

- test-network: Hyperledger Fabric test network
- halal-certification: Smart contracts (chaincode)
- halal-certification-app: Frontend and backend application

## Prerequisites

- Docker & Docker Compose
- Node.js (v18+ recommended)
- Hyperledger Fabric binaries and Docker images

## Setup Overview

1. Start the Fabric test network
2. Deploy the halal certification chaincode
3. Run the backend API
4. Launch the frontend application
